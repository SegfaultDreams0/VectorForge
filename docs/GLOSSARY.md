# Glossary

| Term | Meaning |
|---|---|
| Arc length | Distance measured along a curve |
| Automatic differentiation | Propagation of derivative information through computations |
| Covariance | Matrix describing variance and pairwise uncertainty |
| Curvature | Rate at which a curve changes direction per unit arc length |
| Eigenvalue | Scalar associated with an eigenvector under a linear transformation |
| Extended Kalman Filter | Nonlinear state estimator using local linearization |
| Frenet frame | Curve-attached tangent, normal, and binormal frame |
| Jacobian | Matrix of first-order partial derivatives |
| Lie algebra | Tangent-space algebra associated with a Lie group |
| Lie group | Smooth group structure used to represent transformations |
| Numerical conditioning | Sensitivity of a problem's solution to input perturbations |
| Optimization | Minimization or maximization of an objective |
| Quaternion | Four-component representation commonly used for 3D rotations |
| Residual | Difference between a target or observation and a computed result |
| Rigid-body dynamics | Motion under forces and torques without internal deformation |
| SE(3) | Special Euclidean group of 3D rigid transformations |
| SLERP | Spherical linear interpolation |
| SO(3) | Special orthogonal group of 3D rotations |
| Torsion | Measure of spatial twisting of a curve |
| Trajectory | Parameter- or time-indexed path through a state or configuration space |

These are introductory definitions; see `MATHEMATICS.md` for fuller context.
