# VectorForge Experiments

Exploratory demonstrations and numerical laboratories. These are not stable API guarantees or production-ready systems.

| Script | Focus |
|---|---|
| `CelestialMechanics.lua` | Simplified orbital visualization |
| `OrbitalSimulation.lua` | Two-body Newtonian orbit scaffold |
| `KalmanVisualization.lua` | Noisy observations and smoothed estimate reference |
| `TrajectoryLaboratory.lua` | Parametric path visualization |
| `NumericalStabilityLab.lua` | Floating-point accumulation error |

Run selected scripts from `ServerScriptService` in Studio. Celestial examples are simplified Newtonian/educational models, not general-relativistic simulations. Some scripts include adapters that must be connected to verified module APIs.
