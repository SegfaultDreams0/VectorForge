# Future Algorithms

Candidate directions, not promised implementation work.

| Area | Candidate | Questions |
|---|---|---|
| Linear algebra | Singular Value Decomposition | Which method is robust and feasible in Luau? |
| Estimation | Unscented Kalman Filter | How will sigma points and covariance updates be represented? |
| Optimization | Levenberg-Marquardt | Which least-squares problems are targeted? |
| Geometry | Bézier and spline utilities | What continuity and parameter conventions are required? |
| Dynamics | Constraint-based rigid-body methods | What physical assumptions and stability limits apply? |
| Differentiation | Higher-order derivatives | What performance and memory trade-offs are acceptable? |

Promotion criteria: clear use case, documented mathematics, scoped API proposal, deterministic tests, and a performance plan.
