# Numerical Methods Notes

## Error sources
- Rounding error.
- Truncation error.
- Ill-conditioned inputs.
- Iterative stopping error.
- Accumulated error across repeated operations.

Conditioning describes sensitivity inherent in a problem. Stability describes how an algorithm behaves under finite-precision perturbations. A stable algorithm cannot make an inherently ill-conditioned problem insensitive.

Investigation topics include pivoting strategies, residual-based stopping criteria, compensated summation, finite-difference step selection, and convergence under different input scales.
